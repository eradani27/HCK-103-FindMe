# FindMe

FindMe adalah website sederhana untuk membantu pengelolaan informasi orang hilang dan orang yang telah ditemukan. Website ini memungkinkan pengguna untuk menambahkan, melihat, mengubah, mencari, memfilter, dan menghapus data orang.

## Fitur

- Menampilkan daftar orang hilang dan orang yang telah ditemukan.
- Menambahkan data orang hilang baru.
- Mengubah informasi dan status orang.
- Menghapus data orang yang telah ditemukan.
- Memfilter data berdasarkan seluruh data, masih hilang, atau telah ditemukan.
- Menampilkan salah satu data orang hilang sebagai sorotan utama.

## Teknologi

- HTML
- CSS
- JavaScript

# Tampilan Website

## Cara Menjalankan

1. Clone repository ini:

   ```bash
   git clone https://github.com/eradani27/HCK-103-FindMe.git
   ```

2. Buka folder proyek di Visual Studio Code.
3. Buka file `index.html` melalui browser atau gunakan ekstensi Live Server.
